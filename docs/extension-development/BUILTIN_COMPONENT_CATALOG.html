三层调用模型

不要把宿主 API、组件命令和页面消息桥混为一类。

1. 隔离页面

window.nexora.invoke() 只能启动本组件在 allowedCommands 中允许的命令。

2. Python 组件命令

通过 nexora_sdk 读取项目、保存状态、调用依赖并上报日志与进度。

3. Component Bridge

call_component() 只能调用 Manifest 已声明依赖且目标公开登记的命令。

文件操作是唯一公开文件服务。

新组件应声明 nexora.file-operations 依赖并通过 call_component() 调用。旧 builtin.project-resources 只是已安装方案的内部兼容标识，不是新的调用目标，也不会出现在普通组件目录。

文件操作组件

nexora.file-operations 是项目文件、受授权外部目录、缓存与 Watcher 的稳定公共服务。

路径不是裸字符串。

项目文件使用 {"space":"project","path":"assets/a.png"}；外部文件使用 {"space":"external","grantId":"…","path":"D:\\Media\\a.png"}。项目路径拒绝绝对路径、..、.pm_center、符号链接与 Junction 越界。外部路径必须位于同一组件获得的目录授权内。

命令组公开命令所需能力语义
项目与目录project.describe · directory.list · entry.stat · entry.exists · entry.searchproject.files.read 或 filesystem.external.read分页、排序、名称/路径/扩展名/类型搜索；source=auto|cache|disk。
读取与写入file.read · file.write · file.hash · directory.create项目或外部读取/写入单次读写最大 4 MiB；写入使用临时文件与原子替换；expectedHash 防止覆盖并发修改。
变更entry.copy · entry.move · entry.rename · entry.delete · batch.execute由源和目标空间分别计算冲突策略 error、overwrite、rename、skip；默认删除进回收站，永久删除必须显式 permanent=true。
流stream.open-read · stream.read · stream.open-write · stream.write · stream.commit · stream.abort项目或外部读取/写入分块最大 1 MiB，句柄绑定组件与授权，15 分钟超时；停用组件时写入临时文件被清理。
授权与跨空间external.select · external.grant-directory · external.list-grants · external.revoke-grant · external.import · external.exportfilesystem.dialog.open、外部读写、项目读写授权可为 once、session 或 persistent；授权属于设备，不写入方案。导入/导出使用同一复制合同。
缓存与监听cache.status · cache.query · cache.invalidate · cache.refresh-directory · cache.rebuild-project · watcher.statuscache.inspect 或 cache.maintain不暴露 TreeCache SQL 或文件；写入立即失效受影响缓存，重建作为受监督组件操作记录，不改变项目数据库。
from nexora_sdk import call_file_operation, project_location

location = project_location("assets/notes.txt")
result = call_file_operation(
    "file.write",
    {"location": location, "encoding": "text", "data": "hello", "expectedHash": None},
    capability="project.files.write",
)

# 外部目录必须先由 external.select 或 external.grant-directory 获得 grantId。
# external_location(r"D:\\Media\\ref.png", grant_id) 不能越过该授权目录。

当前公开边界

这些限制应直接影响组件设计，不应通过内部命令名绕过。

没有运行时接口发现

当前应阅读目标组件 Manifest 与本目录；还没有面向第三方的“列出所有公开命令”SDK。

没有通用跨组件事件总线

组件命令可以互调，通用 publish/subscribe 仍为 reserved-r17；当前事件由宿主自动化白名单提供。

项目接口尚不等于项目管理器

集合、标签、最近项目、项目根目录扫描和项目主页命令尚未作为稳定第三方 SDK 开放。

隔离页面不能直接访问宿主

页面不能调用 Tauri、React Store、数据库、本机路径或其他组件，只能启动本组件允许的命令。

命令可声明多项 Capability

requiredCapabilities 可表达跨空间操作所需的权限集合；旧 requiredCapability 仍兼容为单元素数组。调用方和目标组件都必须声明对应 Capability。

受控 UI 扩展

目标组件通过 uiExtensionPoints 发布命名插槽或整页替换点。扩展组件必须声明目标依赖和自身 scriptSurface；页面仍不能注入 React Store、宿主 DOM 或 Tauri API。
