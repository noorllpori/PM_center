# R5-2 设置区与右键命令贡献

> 状态：`verifying`
>
> 日期：2026-08-04
>
> 基线版本：2.8.4

## 1. 本轮目标

让已有设置区和文件右键扩展跟随模块贡献动态出现、撤下，继续验证“停用模块不仅隐藏主入口，也撤下模块拥有的次级界面和命令”。

本轮不把整个设置面板或整个文件右键菜单归给某个模块。核心设置与普通文件系统命令继续由应用核心提供。

## 2. 稳定贡献

新增并接入以下稳定贡献 ID：

| 贡献 ID | 类型 | 所属模块 | 管理内容 |
| --- | --- | --- | --- |
| `builtin.automation-runtime.settings-section` | `settingsSections` | `builtin.automation-runtime` | 全局任务脚本、全局插件、项目插件设置 |
| `builtin.automation-runtime.plugin-context-commands` | `contextCommands` | `builtin.automation-runtime` | 文件和目录背景中的旧插件动作及插件调试信息 |
| `builtin.project-resources.collection-context-commands` | `contextCommands` | `builtin.project-resources` | 创建集合、加入集合、移出集合及集合维护命令 |

Rust 内置模块 manifest 与前端贡献目录使用相同 ID。现有唯一性测试会拒绝同一贡献类型中的重复 ID。

## 3. 设置区行为

- 自动化运行时正常运行时，原有任务脚本和插件设置保持不变；
- 模块停用后，三个自动化设置区域立即撤下，其他全局和项目设置仍可使用；
- 插件描述、目录、草稿、展开状态和进行中状态从界面内存清理，不删除磁盘插件、依赖或设置数据；
- 模块停用期间不再发起新的插件扫描；
- 已经发出的异步请求在返回时重新检查贡献状态，不再写回过期界面或弹出失去上下文的错误；
- 模块重新启用后重新读取原有插件和设置数据，不自动执行插件任务。

## 4. 右键命令行为

- 自动化运行时不可用时，不加载、计算或显示插件右键动作；
- 已打开的插件子菜单在贡献撤下后自动关闭；
- 点击和真正执行之间发生模块停用时，执行前会再次检查贡献，拒绝竞态调用；
- 项目资源贡献不可用时，集合命令撤下；
- 打开、剪切、复制、粘贴、重命名、删除、详细信息和系统右键菜单始终保留；
- 插件菜单顺序、多选文件上下文和原有插件数据格式没有变化。

## 6. 人工验收

- [ ] 自动化运行时启用时，全局任务脚本、全局插件和项目插件设置可见；
- [ ] 停用 `builtin.automation-runtime` 后，上述三个区域立即消失，设置面板其他内容仍可用；
- [ ] 文件和目录背景右键菜单中的插件项、插件子菜单和插件调试项消失；
- [ ] 打开、复制、粘贴、重命名、删除、详细信息等核心命令仍存在；
- [ ] 重新启用自动化运行时后，插件设置和右键动作恢复，插件数据未丢失且没有任务自动开始；
- [ ] 集合创建、加入、移出、重命名和删除命令在项目资源模块正常时可用；
- [ ] 模块切换时保持右键菜单打开，确认旧子菜单会关闭且不会执行已经撤下的命令；
- [ ] 检查文件列表、目录树和目录背景三种右键入口；
- [ ] 检查浅色、深色和窄窗口设置面板布局。

## 7. 未包含

- 不改变旧插件 manifest、动作排序、设置存储或依赖目录；
- 不把普通文件系统命令改造成可卸载贡献；
- 不增加用户可编辑的右键菜单布局；
- 不实现 Widget、DataSource 或工作流节点运行时；
- 不升级版本号。

## 8. 回滚与数据安全

本轮没有数据库迁移。回滚前端贡献过滤不会删除 Pin、项目会话、插件、插件依赖、插件设置、集合或项目数据。后端 R4 命令守卫仍是最终安全边界。
