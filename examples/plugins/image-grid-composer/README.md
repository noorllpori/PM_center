# 图片排序排版工具

打开一个本地 Tk 窗口，把图片或图片文件夹加入列表，按文件名自然排序后合成为带标题的黑底网格图。

## 使用方式

- 在 Nexora 工具栏的插件菜单中打开，手动添加图片或文件夹。
- 在文件区右键选中一张或多张图片，通过“图片工具 / 图片排序排版工具”打开，选中的图片会自动进入列表。
- 输出图顶部标题会自动使用保存文件名去掉扩展名后的文本，并可关闭；默认显示抬头。
- 可以选择不缩小，或把每张图片等比限制在 360p、540p、720p、1080p 尺寸内。
- 可以导出 PNG 或 JPG；默认导出 PNG，并默认在每张图片下方写入名称。

## 依赖

- `Pillow` 用于读取、缩放和保存图片。
- `tkinterdnd2` 用于拖拽导入；未安装时仍可通过按钮添加图片。

如果运行时提示缺少依赖，请到设置里的插件面板安装该插件依赖。
