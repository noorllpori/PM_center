# 空白主页模板

这是一个可从本地目录安装的最小 Shell 模板。模板初始不装配任何内容，所以工具带以下会保持完全空白。它只声明一个“主页区域”，用户可以在装配方案中显式加入“主页 / 当前活动页面”。

## 安装

1. 在 Nexora 打开“维护中心（或恢复设置） -> 高级诊断 -> 组件运行时”。
2. 点击“从目录安装”。
3. 选择本目录：`E:\PM_center\examples\templates\blank-home-template`。

安装后，模板组件 ID 为 `example.blank-home-template`，模板 ID 为 `example.shell.blank-home`。

## 使用

1. 打开当前方案的“编辑装配方案”。
2. 在“界面装配 -> 安装的界面模板”选择“空白主页 · 空白主页模板”。
3. 在“模板插槽 -> 主页区域”中加入“主页 / 当前活动页面”。
4. 在页面底部“启动主页”选择要显示的页面，例如“Ninniku 音乐播放器”；保持默认时显示 Nexora Logo 欢迎页。
5. 点击“保存并应用”。

旧模板中的导航、快捷栏和插槽绑定会保留在各自模板的状态中；切回原模板后会恢复。没有向主页区域加入内容时，主界面保持空白；加入主页但没有选择其他启动页面时，主页区域显示 Nexora Logo 欢迎页。这个模板不会读取或修改项目文件，也不包含 JavaScript。
