# 左右对半界面模板

这是一个独立的 Nexora `data-pack` 样例。桌面宽度下左右各占 50%，宽度低于 720px 时改为上下各占 50%。

## 安装

1. 打开 `工具 Alt+Q -> 维护中心 -> 组件运行时`。
2. 点击“从目录安装”。
3. 选择本目录 `examples/split-interface-template`，也就是直接包含 `component.json` 的目录。
4. 在当前装配方案中启用“左右对半界面模板”。

## 装配

1. 打开“编辑装配方案 -> 界面装配”。
2. 在“安装的界面模板”选择“左右对半布局”。
3. 左侧区域选择一个组件页面，例如 Ninniku 音乐播放器。
4. 右侧区域加入“主页 / 当前活动页面”，或选择另一个组件页面。
5. 根据需要在页面底部选择启动主页。
6. 点击“保存并应用”。

两个插槽都是可选的，并且 `collapseWhenEmpty` 为 `false`，所以没有绑定时仍保留空白的半屏区域。

## 开发重载

已安装目录不是源码目录。长期修改时，在界面装配中选择该模板并点击“复制为开发模板”，然后：

1. 用 VS Code 打开生成的受信任开发目录。
2. 修改并保存 HTML/CSS/JSON。
3. 回到 Nexora 点击模板旁“重载”，或点击顶部 `DEV` 扫描并重载变化。
4. 只有插槽绑定或主页等 Profile 内容变化时才点击“保存并应用”。

完整说明见 `docs/extension-development/INTERFACE_TEMPLATE_DEVELOPMENT_GUIDE.md`。
